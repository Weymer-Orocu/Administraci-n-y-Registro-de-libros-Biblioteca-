# 📚 Sistema de Gestión de Biblioteca (Java Swing)

Aplicación de escritorio desarrollada en **Java** utilizando **Apache NetBeans IDE 30** para la gestión y administración de registros de libros en una biblioteca. El proyecto implementa una interfaz gráfica de usuario (GUI) amigable y aplica los principios fundamentales de la Programación Orientada a Objetos (POO).

## 🚀 Características Principales
* 📖 **Gestión de Libros:** Registro, consulta y control de la información de los libros.
* 🖥️ **Interfaz Gráfica (GUI):** Ventanas e interfaz de usuario desarrolladas en Java Swing.
* 🏗️ **Arquitectura Limpia:** Separación clara entre la lógica de negocio, los modelos de datos y la vista de la aplicación.
---
## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java
* **Interfaz Gráfica:** Java Swing
* **IDE:** Apache NetBeans IDE 30
* **Paradigma:** Programación Orientada a Objetos (POO)
